## Следующая задача: Footer

**Проблема:** В проекте нет Footer компонента — последнего обязательного элемента лендинга

**Цель:** Спроектировать и создать несколько вариантов Footer компонентов

### Требования к Footer

**Обязательные элементы:**

- Логотип / название компании с иконкой
- Контактная информация:
  - Телефон с иконкой и графиком работы
  - Email с иконкой
  - Физический адрес с иконкой
- Социальные сети (VK, Telegram, WhatsApp) — иконки + ссылки
- Навигация (дублирование меню из Header)
- Copyright текст
- Год автоматически (JavaScript)

**Технические требования:**

- Responsive: desktop → tablet → mobile
- Tailwind CSS only (no custom CSS)
- Remix Icons для всех иконок
- Mobile-first подход
- Тёмный фон (bg-gray-900 / bg-gray-800) — типично для футеров
- Светлый текст (text-gray-300 / text-white)

## Варианты Footer для обсуждения

### Вариант 1 — Footer с Яндекс Картой

**Концепция:** Футер с интегрированной Яндекс Картой для показа местоположения офиса/сервиса.

**Структура:**

- **Верхняя секция (3 колонки на десктопе):**
  - Колонка 1: Логотип + краткое описание
  - Колонка 2: Контакты (телефон, email, адрес)
  - Колонка 3: Навигация + соцсети
- **Средняя секция:**
  - Яндекс Карта (iframe, высота 300-400px)
  - Маркер с адресом компании
- **Нижняя секция:**
  - Copyright + год
  - Опционально: ссылки на политику конфиденциальности

**Плюсы:**
- Клиенты сразу видят где находится сервис
- Повышает доверие (реальный адрес)
- Удобно для планирования визита

**Минусы:**
- Увеличивает высоту футера
- Требует координат для карты

---

### Вариант 2 — Footer без Карты (компактный)

**Концепция:** Классический компактный футер без карты, фокус на контактах и навигации.

**Структура:**

- **Основная секция (4 колонки на десктопе → 2 → 1):**
  - Колонка 1: Логотип + краткое описание
  - Колонка 2: Контакты (телефон, email, адрес, график)
  - Колонка 3: Навигация (быстрые ссылки)
  - Колонка 4: Социальные сети + CTA кнопка
- **Нижняя секция:**
  - Copyright + год + доп. ссылки

**Плюсы:**
- Компактный, не занимает много места
- Быстрая загрузка (нет iframe карты)
- Хорошо сканируется

**Минусы:**
- Нет визуального представления местоположения

---

### Вариант 3 — Footer с Формой Обратной Связи

**Концепция:** Футер с формой подписки на рассылку или быстрой заявки.

**Структура:**

- **Основная секция (2 колонки на десктопе):**
  - Левая колонка (60%):
    - Логотип
    - Контакты (телефон, email, адрес)
    - Навигация + соцсети
  - Правая колонка (40%):
    - Заголовок формы ("Получить консультацию", "Подписаться на акции")
    - Форма:
      - Поле Имя
      - Поле Телефон
      - Кнопка Submit (красная/зелёная)
    - Текст про политику конфиденциальности
- **Нижняя секция:**
  - Copyright + год

**Плюсы:**
- Дополнительная точка конверсии
- Собираем лиды даже внизу страницы
- Подписка на акции/рассылку

**Минусы:**
- Увеличивает высоту футера
- Требует обработки формы (может быть просто HTML)

---

### Вариант 4 — Footer с CTA Кнопкой и Акцией

**Концепция:** Футер с выделенным блоком акции и призывом к действию.

**Структура:**

- **Верхняя секция (цветная, например bg-green-600):**
  - Заголовок акции: "Скидка 20% на первый ремонт!"
  - Текст: "Оставьте заявку прямо сейчас"
  - Крупная CTA кнопка: "Вызвать мастера"
  - Телефон с иконкой
- **Основная секция (тёмная bg-gray-900):**
  - 3 колонки: Логотип + описание | Навигация | Контакты + соцсети
- **Нижняя секция:**
  - Copyright + год

**Плюсы:**
- Яркий акцент на акции
- Последний шанс конвертировать посетителя
- Заметный CTA внизу страницы

**Минусы:**
- Может выглядеть слишком агрессивно

---

### Вариант 5 — Минималистичный Footer (одноколоночный)

**Концепция:** Простой центрированный футер для минималистичного дизайна.

**Структура:**

- **Центрированная колонка:**
  - Логотип с иконкой (центр)
  - Телефон + график работы (центр)
  - Соцсети (иконки в ряд, центр)
  - Навигация (горизонтальный список, центр)
  - Copyright (центр)

**Плюсы:**
- Очень чистый дизайн
- Хорошо работает на мобильных
- Быстрая загрузка

**Минусы:**
- Меньше информации
- Не подходит если много контента

## Яндекс Карта — Интеграция

**HTML код для Яндекс Карты:**

```html
<div class="w-full h-[300px] md:h-[400px] rounded-lg overflow-hidden">
  <iframe
    src="https://yandex.ru/map-widget/v1/?um=constructor%3A{MAP_ID}&amp;source=constructor"
    width="100%"
    height="100%"
    frameborder="0"
    loading="lazy"
  ></iframe>
</div>
```

**Как получить MAP_ID:**
1. Открыть Яндекс Конструктор карт: https://yandex.ru/map-constructor/
2. Указать адрес
3. Настроить маркер
4. Скопировать код iframe
5. Извлечь MAP_ID из URL

**Для демо:** Использовать placeholder координаты (например, центр Москвы)
