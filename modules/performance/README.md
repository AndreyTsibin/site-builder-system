# Performance Module

Lighthouse performance audit for landing pages.

## Description

This module runs performance audits using Lighthouse to ensure optimal loading speed and Core Web Vitals.

## Usage

```bash
# Run performance audit
python3 audit.py
```

## Features

- Runs Lighthouse audit (desktop + mobile)
- Checks Core Web Vitals (LCP, FID, CLS)
- Measures Time to Interactive (TTI)
- Measures First Contentful Paint (FCP)
- Generates performance report
- Suggests optimization recommendations

## Performance Targets

- PageSpeed Score: >90 (mobile + desktop)
- Time to Interactive: <3s
- First Contentful Paint: <1.8s
- Largest Contentful Paint: <2.5s
