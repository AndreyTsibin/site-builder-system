# Accessibility Module

WCAG compliance checker for landing pages.

## Description

This module checks landing pages for accessibility compliance (WCAG 2.1 AA).

## Usage

```bash
# Run accessibility check
python3 check.py
```

## Features

- Checks semantic HTML structure
- Validates ARIA attributes
- Checks color contrast ratios
- Validates alt texts for images
- Checks keyboard navigation support
- Generates accessibility report
