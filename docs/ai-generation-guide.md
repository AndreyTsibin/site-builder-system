## Введение

### Зачем нужна AI-генерация?

После сборки лендинга через Python скрипт (`assemble.py`) вы получаете HTML-файл с плейсхолдерами в формате `{{section.variable}}`. Эти плейсхолдеры нужно заменить на реальный контент вашего бизнеса.

**Два сценария:**
1. **Данные есть** → Claude заполняет плейсхолдеры из `business-data.md`
2. **Данных нет** → Claude генерирует релевантный контент на основе типа бизнеса

### Преимущества AI-подхода

- ⚡ **Быстро:** Заполнение всех плейсхолдеров за 2-5 минут
- 🎯 **Точно:** Использует ваши бизнес-данные из `business-data.md`
- 🧠 **Умно:** Генерирует контент, если данных недостаточно
- 🔄 **Консистентно:** Соблюдает тон, стиль, структуру

## Workflow генерации контента

### Шаг 1: Подготовка данных

1. Откройте `templates/business-data.md`
2. Заполните все разделы данными вашего бизнеса:
   - Основная информация (название, город, год)
   - УТП (уникальные торговые предложения)
   - Услуги и цены
   - Контакты (телефон, email, адрес)
   - Соцсети
   - Дополнительная информация

**Важно:** Чем подробнее заполните — тем точнее будет результат.

### Шаг 2: Сборка лендинга

```bash
python scripts/assemble.py --config templates/selected-sections.json
```

Результат: `output/{project_name}/index.html` с плейсхолдерами

### Шаг 3: Заполнение плейсхолдеров с Claude

Скопируйте [основной промпт](#основной-промпт-для-claude) ниже, вставьте в Claude Code CLI и запустите.

### Шаг 4: Проверка

1. Откройте `output/{project_name}/index.html` в браузере
2. Проверьте, что все плейсхолдеры заменены на контент
3. Проверьте корректность данных (телефон, email, адрес)
4. Проверьте отсутствие кракозябр (UTF-8 encoding)

## Основной промпт для Claude

### 📋 Копируйте этот промпт в Claude Code CLI

```markdown
Заполни все плейсхолдеры {{...}} в файле output/{project_name}/index.html используя данные из templates/business-data.md.

ПРАВИЛА ЗАПОЛНЕНИЯ:

1. ИСТОЧНИК ДАННЫХ:
   - Читай business-data.md построчно
   - Используй ТОЛЬКО данные из этого файла
   - Сохраняй форматирование (телефон +7 (999) 123-45-67)

2. ЕСЛИ ДАННЫХ НЕТ В BUSINESS-DATA.MD:
   - Генерируй релевантный контент на основе типа бизнеса
   - Используй реалистичные примеры
   - Соблюдай тон и стиль (профессиональный, дружелюбный)
   - НЕ используй слова "пример", "шаблон", "замените"

3. ПЛЕЙСХОЛДЕРЫ ПО КАТЕГОРИЯМ:

   a) {{meta.title}} и {{meta.description}}:
      - title: Название компании + тип услуги + город
      - description: 120-160 символов, включить УТП

   b) {{logo.text}}:
      - Название компании из раздела "Основная информация"

   c) {{nav.item1}}, {{nav.item2}}, {{nav.item3}}:
      - 3 главных раздела сайта (Услуги, О нас, Контакты)
      - Короткие названия (1-2 слова)

   d) {{contacts.phone}}:
      - Формат: +7 (999) 123-45-67 (без "тел:", без "звоните")
      - Для tel: атрибутов — тот же формат

   e) {{hero.title}}, {{hero.subtitle}}:
      - title: Главный оффер (до 60 символов)
      - subtitle: Расшифровка оффера + УТП (до 150 символов)

   f) {{hero.cta_text}}, {{header.cta_text}}:
      - Глагол + результат ("Заказать консультацию", "Вызвать мастера")

   g) {{features.section_title}}:
      - Заголовок секции преимуществ ("Почему выбирают нас", "Наши преимущества")

   h) {{features.itemN.icon}}:
      - Remix Icon class (примеры: ri-shield-check-line, ri-time-line, ri-tools-line)
      - Выбирай иконки, соответствующие смыслу преимущества

   i) {{features.itemN.title}} и {{features.itemN.text}}:
      - Используй УТП из раздела "2. УТП"
      - title: краткое название (3-5 слов)
      - text: расшифровка (до 100 символов)

   j) {{cta.title}}, {{cta.text}}, {{cta.button_text}}:
      - title: Призыв к действию (до 40 символов)
      - text: Усилитель (скидка, бонус, гарантия)
      - button_text: Глагол ("Получить консультацию")

   k) {{footer.copyright}}:
      - Формат: "© 2025 Название компании. Все права защищены."

   l) {{social.vk}}, {{social.telegram}}, {{social.whatsapp}}, {{social.instagram}}:
      - Ссылки из раздела "5. Соцсети"
      - Если нет в business-data — оставь плейсхолдер (НЕ генерируй фейковые ссылки)

4. КАЧЕСТВО КОНТЕНТА:
   - Грамотный русский язык (без ошибок)
   - Профессиональный, но дружелюбный тон
   - Конкретика: цифры, факты, гарантии
   - NO: штампы ("мы лучшие"), общие фразы ("высокое качество")
   - YES: специфика ("гарантия 3 года", "выезд за 1 час")

5. UTF-8 ENCODING:
   - После заполнения проверь кириллицу
   - Команда: head -50 output/{project_name}/index.html
   - Если кракозябры — перезапиши файл с UTF-8

6. ПРОВЕРКА:
   - Все плейсхолдеры {{...}} заменены (кроме соцсетей без данных)
   - Телефоны в правильном формате
   - Email корректный
   - Иконки Remix Icon существуют

Начинай работу. После заполнения сообщи о завершении и запусти проверку.
```

## Примеры плейсхолдеров

### Мета-теги

```html
<meta name="description" content="{{meta.description}}">
<title>{{meta.title}}</title>
```

**Заполнение:**
```html

```

```html
<span class="header__logo-text">{{logo.text}}</span>
<a href="#services">{{nav.item1}}</a>
<a href="#about">{{nav.item2}}</a>
<a href="#contacts">{{nav.item3}}</a>
```


```html
<a href="tel:{{contacts.phone}}">{{contacts.phone}}</a>
```

**Заполнение:**

```html
<h1>{{hero.title}}</h1>
```

## Правила генерации контента

### Когда генерировать контент?

Генерируй контент ТОЛЬКО если:
- Данных нет в `business-data.md`
- Данные неполные (например, УТП только 2 из 5)
- Нужны технические элементы (иконки Remix Icon)

### Как генерировать качественный контент?

#### 1. Используй контекст бизнеса

**Плохо:**
```
Мы предлагаем качественные услуги по доступным ценам.
```

**Хорошо:**
```
Ремонтируем стиральные машины всех брендов с гарантией до 3 лет. Выезд мастера в течение часа.
```

#### 2. Конкретика вместо общих фраз

**Плохо:**
```
Быстро выполняем заказы
```

**Хорошо:**
```
Выезд мастера в течение 1 часа, ремонт на месте за 30-60 минут
```

#### 3. Цифры и факты

**Плохо:**
```
Большой опыт работы
```

**Хорошо:**
```
Более 5000 выполненных заказов, 12 лет на рынке
```

#### 4. Выгоды для клиента

**Плохо:**
```
Используем современное оборудование
```

**Хорошо:**
```
Точная диагностика за 15 минут — экономим ваше время и деньги
```

### Выбор иконок Remix Icon

**Категории иконок:**

- **Скорость, время:** `ri-time-line`, `ri-timer-flash-line`, `ri-speed-line`
- **Качество, надежность:** `ri-shield-check-line`, `ri-award-line`, `ri-medal-line`
- **Инструменты, ремонт:** `ri-tools-line`, `ri-settings-line`, `ri-hammer-line`
- **Деньги, цены:** `ri-money-dollar-circle-line`, `ri-price-tag-line`, `ri-coupon-line`
- **Поддержка, сервис:** `ri-customer-service-line`, `ri-service-line`, `ri-phone-line`
- **Локация:** `ri-map-pin-line`, `ri-map-2-line`, `ri-route-line`
- **Гарантия:** `ri-check-double-line`, `ri-checkbox-circle-line`, `ri-verified-badge-line`

**Полный список:** https://remixicon.com/

## Проверка результата

### Чек-лист после заполнения

- [ ] **Все плейсхолдеры заменены** (кроме соцсетей без данных)
- [ ] **Телефоны корректны:** формат +7 (999) 123-45-67
- [ ] **Email корректен:** существующий домен
- [ ] **Иконки Remix Icon валидны:** проверь на remixicon.com
- [ ] **UTF-8 encoding:** нет кракозябр в кириллице
- [ ] **Контент логичен:** соответствует типу бизнеса
- [ ] **Тон единообразен:** профессиональный, дружелюбный
- [ ] **Грамматика:** нет ошибок, опечаток

### Команды для проверки

**1. Проверка UTF-8:**
```bash
head -50 output/{project_name}/index.html
```

**2. Поиск незаполненных плейсхолдеров:**
```bash
grep "{{" output/{project_name}/index.html
```

Если команда вернула результат — есть незаполненные плейсхолдеры.

**3. Открыть в браузере:**
```bash
open output/{project_name}/index.html
```

Визуально проверь:
- Все тексты на месте
- Телефон кликабельный (открывает звонилку)
- Email кликабельный (открывает почтовый клиент)
- Иконки отображаются

## Troubleshooting

### Проблема 1: Кракозябры вместо кириллицы

**Причина:** Неправильная кодировка при записи файла

**Решение:**
1. Проверь кодировку:
   ```bash
   file -I output/{project_name}/index.html
   ```
   Должно быть: `charset=utf-8`

2. Перезапиши файл с явным указанием UTF-8:
   ```python
   with open('index.html', 'w', encoding='utf-8') as f:
       f.write(content)
   ```

3. Проверь:
   ```bash
   head -20 output/{project_name}/index.html
   ```

### Проблема 2: Остались незаполненные плейсхолдеры

**Причина:** Данных нет в `business-data.md`, а Claude не сгенерировал контент

**Решение:**
1. Найди незаполненные плейсхолдеры:
   ```bash
   grep "{{" output/{project_name}/index.html
   ```

2. Проверь `business-data.md` — есть ли данные для этих плейсхолдеров

3. Либо заполни `business-data.md`, либо вручную сгенерируй контент

### Проблема 3: Иконки не отображаются

**Причина:** Неправильный класс иконки или не подключен Remix Icon CDN

**Решение:**
1. Проверь подключение CDN в `<head>`:
   ```html
   <link href="https://cdn.jsdelivr.net/npm/remixicon@4.0.0/fonts/remixicon.css" rel="stylesheet">
   ```

2. Проверь класс иконки на сайте: https://remixicon.com/

3. Формат класса: `ri-{name}-{style}` (например, `ri-shield-check-line`)

### Проблема 4: Телефон не кликабельный

**Причина:** Неправильный формат в атрибуте `href="tel:"`

**Решение:**

**Неправильно:**
```html
<a href="tel:+7(999)123-45-67">  <!-- без пробелов -->
<a href="tel:8 999 123-45-67">   <!-- начинается с 8 -->
```

**Правильно:**
```html
<a href="tel:+7 (999) 123-45-67">+7 (999) 123-45-67</a>
```

### Проблема 5: Контент звучит шаблонно

**Причина:** Claude генерирует общие фразы вместо конкретики

**Решение:**
1. Заполни больше данных в `business-data.md`:
   - УТП (все 5 пунктов)
   - Статистика (цифры)
   - Целевая аудитория

2. Уточни промпт для Claude:
   ```
   Используй конкретные цифры, факты, гарантии из business-data.md.
   НЕ используй общие фразы вроде "высокое качество", "лучший сервис".
   ```

### Проблема 6: Тон контента не соответствует бренду

**Причина:** Claude не учёл раздел "Примечания для Claude" в `business-data.md`

**Решение:**
1. Открой `business-data.md`, раздел "7. Примечания для Claude"

2. Укажи тон:
   ```
   - Тон: дружелюбный, неформальный (можно "вы", эмодзи)
   - Избегай: официоз, канцеляризмы, штампы
   ```

3. Повтори генерацию с новыми инструкциями
