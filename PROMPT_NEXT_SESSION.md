## Задача для новой сессии

### Цель: Исследовать и добавить новые типы секций

**Что делаем:**

1. **Анализируем существующие секции** — какие есть в проекте
2. **Исследуем рынок** — используя веб-поиск:
   - Какие секции используют конкуренты
   - Что популярно в нише ремонта/сервиса
   - Тренды веб-дизайна 2025 для лендингов
   - Best practices для конверсионных лендингов
3. **Обсуждаем идеи** — какие секции могут быть полезны
4. **Планируем добавление** — приоритизируем и разрабатываем

### Возможные направления для исследования:

**Секции, которых может не хватать:**

- **Trust Badges / Гарантии** — логотипы партнёров, сертификаты, награды
- **Before/After / До и После** — фото результатов работы
- **Team / Команда** — фото мастеров, опыт, специализация
- **Coverage Area / Зона покрытия** — карта районов обслуживания
- **Stats / Статистика** — цифры о компании (X лет, Y клиентов, Z ремонтов)
- **Blog Posts / Статьи** — последние публикации/советы
- **Video Section / Видео** — видео о компании или процессе работы
- **Timeline / Таймлайн** — история компании
- **Comparison / Сравнение** — почему мы vs конкуренты
- **Emergency Banner / Экстренный баннер** — срочный вызов, аварийная служба
- **Calculator / Калькулятор** — расчёт стоимости ремонта
- **Portfolio Grid / Портфолио** — галерея выполненных работ

### Как работаем:

1. **Веб-поиск** — ищем референсы, тренды, best practices
2. **Обсуждение** — анализируем находки, выбираем лучшее
3. **Приоритизация** — решаем, что добавлять в первую очередь
4. **Проектирование** — описываем структуру и варианты каждой секции
5. **Разработка** — создаём компоненты по стандартам проекта

## Стандарты проекта (краткая справка)

**Tech Stack:** Astro 5.15.2, Tailwind CSS 4.1.16, Remix Icons 4.7.0

**Layout стандарты:**
- Container: `max-w-[1344px] mx-auto px-4 sm:px-6 lg:px-8`
- Section padding: `py-16 md:py-20 lg:py-24`
- Mobile-first подход

**Принципы:**
- Tailwind CSS only (no custom CSS)
- Props-based компоненты
- Responsive дизайн
- Accessibility (ARIA, semantic HTML)
- UTF-8 для кириллицы

**Git:**
- Branch: `design`
- Commit format: `feat:`, `fix:`, `refactor:`
